# Remix of Youthoria Vibes

YOUTHORIA PODCAST – WEBSITE SPECIFICATION

Create a modern, premium, highly interactive, fully responsive website for Youthoria Podcast.

General Concept

Youthoria Podcast is a podcast created by young people, for young people. The website should communicate creativity, authenticity, innovation and youth culture.

The design should feel like an award-winning website with lots of smooth animations, premium interactions and an immersive experience.

The website should have a modern aesthetic inspired by Apple, Stripe, Linear, Framer and Awwwards websites.

Everything should feel alive.

CMS

Create an admin dashboard where administrators can:

Edit pages.

Edit team members.

Manage translations.

Manage Atlas regions.

Manage donation popup.

Manage homepage.

Even though episodes sync automatically from Spotify, administrators should still be able to feature or pin specific episodes.



Technology

Use modern technologies such as Next.js, React, Tailwind CSS and Framer Motion for animations.

The Spotify integration should use the Spotify API or RSS feed to automatically display new episodes.

The code should be clean, scalable and production-ready.



Overall Goal

The final website should feel premium, emotional and memorable.

Visitors should immediately understand that Youthoria Podcast is an innovative youth project.

The website should have the quality of an international creative agency and be visually impressive enough to be featured on Awwwards.
